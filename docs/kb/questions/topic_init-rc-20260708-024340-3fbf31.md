# Research Goal: Adaptive Speculative Decoding via Dynamic Token Entropy

- **Topic**: LLM Inference Optimization (Specifically: Speculative Decoding)
- **Novel Angle**:
    - **The Gap**: Current Speculative Decoding (SD) methods (e.g., Medusa, EAGLE, Lookahead) rely on **static** or **fixed-window** draft models. They either draft a fixed number of tokens (e.g., 5) regardless of context difficulty, or use a separate small model that is always active. This creates a "compute tax" even when the main model is highly confident (easy tokens) or when the draft model is likely to fail (hard tokens).
    - **The Opportunity (2024-2026)**: Recent work (2024) like *Medusa-2* and *EAGLE-2* has shown that draft models can be highly accurate, but the *overhead* of running the draft head for *every* token remains a bottleneck. The industry is shifting toward "adaptive" inference (e.g., *H2O*, *StreamingLLM*), but no SD method dynamically adjusts the **draft depth** based on real-time **token-level uncertainty** without adding a heavy secondary classifier.
    - **Differentiation**: Unlike standard SD which is "Draft N, Verify N", this research proposes a **"Confidence-Triggered Drafting"** mechanism. The system estimates the main model's entropy *before* drafting. If entropy is low (high confidence), it skips drafting entirely (standard greedy). If entropy is high, it triggers a lightweight, context-aware draft *only then*. This turns SD from a "always-on" optimization into a "conditional" acceleration.
    - **Why Now**: With the proliferation of 70B+ models on consumer hardware (single 4090/80GB GPU), the latency overhead of *always* running a draft head is becoming unacceptable for interactive latency-sensitive apps. We need "zero-overhead" SD.

- **Scope**:
    - Focus exclusively on **Speculative Decoding** for **Text Generation** tasks.
    - Target models: Llama-3-8B-Instruct (as the target) and a tiny 100M parameter "Draft Head" (added as a linear layer).
    - Constraint: The method must not require training a separate small LLM (like EAGLE); it must be a lightweight adapter or head.
    - Exclusion: Do not cover KV-cache eviction or quantization; focus purely on the decoding loop logic.

- **SMART Goal**:
    - **Specific**: Implement a "Dynamic Depth Speculative Decoding" (DDSD) algorithm that calculates token entropy to decide whether to invoke the draft head and how many tokens to draft (1 to 5).
    - **Measurable**: Achieve a **15% reduction in total inference time** (measured in tokens/sec) on the *MMLU* and *HumanEval* benchmarks compared to standard EAGLE-2 (fixed depth 5) and Medusa, while maintaining **<0.5% perplexity degradation**.
    - **Achievable**: Requires only a single NVIDIA A100 or 4090 GPU (24GB+ VRAM) to run Llama-3-8B. The draft head is a single linear layer, trainable in <2 hours on 10k tokens.
    - **Relevant**: Directly addresses the "latency wall" in deploying large open-weight models on edge/consumer hardware, a critical 2024-2025 industry pain point.
    - **Time-bound**: Complete the prototype, baseline comparison, and initial ablation study within **10 days** (2-week sprint).

- **Constraints**:
    - **Compute**: Single GPU (NVIDIA 4090 or A100). Max 24GB VRAM.
    - **Time**: 48 hours of active GPU time maximum.
    - **Data**: Use standard subsets of MMLU (5-shot) and HumanEval (0-shot) via `lm-evaluation-harness`.
    - **Tools**: `vLLM` (for baseline SD implementation) or `HuggingFace` `transformers` + custom CUDA kernels (if needed, otherwise pure PyTorch for logic).
    - **Model**: Llama-3-8B (base or instruct).

- **Success Criteria**:
    1.  **Performance**: Measured tokens/sec must exceed the "Standard Greedy" baseline by >20% and the "Fixed EAGLE" baseline by >10% on average across both benchmarks.
    2.  **Quality**: Perplexity on the test set must remain within 1% of the greedy baseline (proving the "conditional" skipping didn't hurt accuracy).
    3.  **Overhead**: The entropy calculation and decision logic must add <1ms of latency per token (proving the "zero-overhead" claim).
    4.  **Publication Readiness**: A clear ablation study showing the correlation between "Token Entropy" and "Draft Success Rate," proving the mechanism works as hypothesized.
