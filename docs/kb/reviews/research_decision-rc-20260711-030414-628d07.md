# Stage 17: Research Decision

## Decision
**REFINE**

## Justification
The decision to **REFINE** is mandated by **Minimum Quality Criterion #3**: "Each condition has results from ≥3 seeds."

While the experiment successfully executed and generated data for 2 baselines (Logistic Regression, Random Forest) across 3 datasets (Criterion #1 met) and defined primary metrics (Criterion #2 met), the experimental design for statistical rigor is insufficient for a paper-ready conclusion.

The analysis explicitly states: *"No paired statistical test was run because this smoke experiment does not expose repeated paired per-seed observations."* The summary shows `n=6` total metric rows, which corresponds to the 6 combinations of 3 datasets × 2 methods. There is no evidence of multiple random seeds (e.g., 3+ runs) per condition. Without multiple seeds per condition, we cannot calculate standard error, confidence intervals, or perform significance tests, which are essential for scientific claims. Additionally, the "Experiment Status" notes that results are "preliminary comparisons" and "cannot be extrapolated as complete paper conclusions."

Therefore, the hypotheses may be sound, but the **experiments need re-tuning** to include repeated runs (seeds) to satisfy statistical rigor before proceeding to writing.

## Evidence
- **Criterion 3 Failure**: The results show `n=6` total rows. With 2 methods and 3 datasets, this implies exactly 1 run per condition. The requirement is ≥3 seeds per condition.
- **Explicit Limitation**: The "Experiment Status" states: "已真实执行轻量真实基准... 不可外推为完整论文结论" (Lightweight real benchmark executed... cannot be extrapolated as complete paper conclusions).
- **Statistical Gap**: The "Statistical Analysis" section confirms: "No confidence interval or significance test is reported because the available artifact does not contain repeated paired samples."
- **Ablation Integrity**: While per-seed values are not identical (as there is only one value), the lack of variance data (std dev is calculated across the 6 total rows, not within conditions) prevents valid statistical inference.

## Next Actions
1.  **Update Experiment Plan**: Modify `exp_plan.yaml` to enforce a minimum of 3 random seeds for every (Dataset, Method) combination.
2.  **Re-run Experiments**: Execute the classification benchmark again, ensuring stratified cross-validation is run with distinct random states (e.g., seeds 42, 43, 44) for each condition.
3.  **Re-analyze**: Generate new results files ensuring the `n` count per condition is ≥3.
4.  **Statistical Validation**: Once re-run, perform paired statistical tests (e.g., Wilcoxon signed-rank or t-test) across seeds to validate if performance differences are significant.
5.  **Re-evaluate**: Re-run the decision criteria check. If ≥3 seeds are present and statistical tests are feasible, reconsider **PROCEED**.
