# EMNETS-RA 架构与可靠性

项目包含 React/TypeScript Web 界面、Python 研究调度、论文评审与资源服务。默认研究采用六个实际执行阶段；历史 26 阶段保留为兼容路径。普通研究报告与 IEEE 论文交付分别配置。

## 研究流程

| 阶段 | 主要工作 | 交接证据 |
| --- | --- | --- |
| ground | 原始任务、可见数据、来源与验收条目 | 原文锚点、任务哈希、数据概览 |
| plan | 方法分析、执行协议和独立设计复核 | 覆盖全部任务条件的方案、方法探针 |
| implement | 生成代码与必要资源 | 语法和入口检查通过的源文件包 |
| execute | 控制器运行程序并按实测错误修复 | 退出码、日志、指标、源码及输出哈希 |
| report | 根据实测数据、图表与推导生成报告 | 真实图片链接、明确适用范围与限制 |
| verify | 对照原始任务独立检查全部交付 | 逐项证据、科学缺口、最终复核记录 |

`backend/agent/researchclaw/orchestration/` 实现阶段编排与交付约束。科学决策和成果翻译有不同责任，但不能以翻译或文件存在代替方法正确性。理论证明、数值测量、图表语义、引用与可复现性分别检查。

## 稳定性与恢复

- 每个 Web 项目在首次启动时固定内容哈希标识的源码快照。后续 worker 和服务重启读取同一版本；旧检查点不会静默绑定到新源码。
- 阶段交接检查文件哈希和原始任务身份。有效中间结果可以复用，未通过校验的候选不会覆盖当前有效产物。
- 局部修订使用明确作用域、原行范围、语法检查和可恢复的整包事务；修订失败或回退保留历史和原科学缺口。
- 自动重试保留连续失败计数，实际阶段成功后才清零。达到三次后持久停止自动重试，等待用户手动恢复。
- 暂停状态和队列变更写入磁盘，重启不会把用户暂停的任务恢复为孤儿任务。排队任务也可暂停或删除。
- 模型流、程序执行与无进展诊断分开显示。前端使用真实阶段状态、耗时和最近检查时间，不以端口存活替代科研完成。

## 方法与证据

命名方法绑定原始公开来源、精确引用、原式与实际函数；代码、公式和统计量的归一化、权重、坐标顺序与不确定性定义保持一致。方法探针采用解析或变形关系，可以发现指定错误，但不构成完整科学证明。

公共来源检索保留原始响应、出处、范围和哈希。JATS/LaTeX/MathML 尽可能逐字保留；缺失公式、元数据和来源范围明确标记为未验证。数据数量匹配不能代替来源成员依据，背景资料不能替代任务要求的主分析。

当前技能库包含五个固定版本来源的 210 项技能，按阶段和任务选择相关内容。许可证、来源版本与逐文件摘要见 `backend/agent/researchclaw/skills/sources.lock.json` 和 [第三方说明](../THIRD_PARTY_NOTICES.md)。技能说明不能覆盖原始任务或输出约束。

## 配置与发布

模型服务地址、API Key 和专属部署策略保留在仓库外的私有环境文件中；公开配置只含模型名称、通用默认值和环境变量入口。用户账号、认证密钥、评审缓存、项目运行目录、研究笔记及测试产物不随公开仓库分发。

模型与服务接入见 [Web 文档](web-workspace.md)，官方评测接入见 [ResearchClawBench 文档](researchclawbench.md)，发布前检查见 [发布说明](publishing.md)。功能联调、内部科学复核和官方 benchmark 评分分别报告。
